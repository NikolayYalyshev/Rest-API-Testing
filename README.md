# Rest-API-Testing  
Проект содержит автоматизированные тесты для публичного REST API сервера, написанные в Postman.

# API Testing: [restful-booker.herokuapp.com]

## Стек технологий  
* **Postman** — создание и запуск тестов.  
* **JavaScript** — написание тестовых скриптов (Pre-request и Post-response).  
* **Newman** — консольный запуск (опционально).  

## 📋 Что протестировано
- [x] **GET** /ping — проверка корректрости работы API-сервера.
- [x] **POST** /auth — создание токена для работы с определёнными запросами.  
- [x] **GET** /booking - проверка наличия записей бронирования и корректности отсутствия дублирующих записей. 
- [x] **POST** /booking — создание бронирования и проверка динамических данных, валидация заголовков.    
- [x] **PUT/PATCH** — обновление данных и валидация заголовков.
- [x] **DELETE** — проверка успешного удаления.

## Как запустить тесты

### Вариант 1: В интерфейсе Postman  
1. Скачайте файлы из папок `collections/`.  
2. В приложении Postman нажмите кнопку **Import** и выберите оба файла.  
3. Выберите импортированное окружение в правом верхнем углу.  
4. Нажмите **Run Collection**.

### Вариант 2: Через консоль (Newman)  
Если у вас установлен Node.js, выполните:  
npm install -g newman  
newman run collections/RestfulBookerTests.postman_collection.json
